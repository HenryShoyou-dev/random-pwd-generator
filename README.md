# Password Generator

A simple command-line password generator built with Python.

## Features

- Generate random passwords with a customizable minimum length
- Option to include numbers
- Option to include special characters
- Automatically checks whether the generated password meets the selected criteria

## Technologies

- Python 3
- `random` module
- `string` module

## How to Run

1. Clone the repository 

```bash
git clone https://github.com/HenryShoyou-dev/password-generator.git
```

2. Navigate to the project directory
cd password-generator

3. Run the program
py random-password-generator.py
